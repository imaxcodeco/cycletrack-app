# Política de Privacidade - CycleTrack

**Última atualização:** 17 de novembro de 2026

## 1. Introdução

Bem-vinda ao CycleTrack. Sua privacidade é nossa prioridade. Esta Política de Privacidade explica como coletamos, usamos, compartilhamos e protegemos suas informações pessoais quando você usa nosso aplicativo de rastreamento de ciclo menstrual e saúde reprodutiva.

Estamos comprometidos com a conformidade com:
- **LGPD** (Lei Geral de Proteção de Dados - Lei nº 13.709/2018) - Brasil
- **GDPR** (Regulamento Geral de Proteção de Dados - UE 2016/679) - União Europeia
- **CCPA** (California Consumer Privacy Act) - Califórnia, EUA

## 2. Dados que Coletamos

### 2.1 Dados Fornecidos por Você

| Categoria | Exemplos | Finalidade |
|-----------|----------|------------|
| **Identificação** | Nome, e-mail, data de nascimento | Criação de conta, personalização |
| **Perfil Reprodutivo** | Comprimento do ciclo, duração da menstruação, contracepção, objetivo (engravidar/evitar/rastrear) | Cálculos de previsão, insights personalizados |
| **Dados de Ciclo** | Datas de início/fim da menstruação, fluxo, sintomas | Rastreamento, previsões, estatísticas |
| **Sintomas** | Tipo, severidade, notas, data/hora | Análise de padrões, alertas de saúde |
| **Peso e Temperatura** | Valores, unidade, data/hora | Rastreamento de saúde, janela fértil (BBT) |
| **Humor** | Estado emocional, notas | Correlação com fases do ciclo |
| **Dados de Gravidez** | Data prevista do parto, marcos, consultas, exames | Acompanhamento gestacional |
| **Preferências** | Idioma, tema, notificações, unidades | Personalização da experiência |

### 2.2 Dados Coletados Automaticamente

| Tipo | Descrição | Finalidade |
|------|-----------|------------|
| **Dados de Uso** | Telas visitadas, ações, tempo de sessão | Melhoria do app, analytics |
| **Dados de Dispositivo** | Modelo, OS, ID de publicidade (opcional) | Compatibilidade, prevenção de fraude |
| **Logs de Erro** | Crash reports, stack traces (via Sentry) | Depuração, estabilidade |
| **Desempenho** | Tempos de carregamento, uso de memória | Otimização |

### 2.3 Dados de Terceiros (com consentimento)

- **Google Fit / Apple Health / Health Connect**: Dados de ciclo, peso, temperatura, frequência cardíaca
- **Google Sign-In**: Nome, e-mail, foto de perfil
- **Firebase Analytics**: Eventos de uso agregados e anonimizados

## 3. Como Usamos Seus Dados

### 3.1 Finalidades Principais (Base Legal: Execução de Contrato / Consentimento)

1. **Fornecer o Serviço**: Rastreamento de ciclo, previsões, insights, modo gravidez
2. **Personalização**: Ajustar previsões baseadas no seu histórico
3. **Sincronização**: Backup na nuvem, sincronização entre dispositivos, Health Connect
4. **Notificações**: Lembretes de período, janela fértil, pílula, consultas

### 3.2 Finalidades Secundárias (Base Legal: Interesse Legítimo / Consentimento)

1. **Analytics**: Entender uso do app para melhorias (dados agregados/anônimos)
2. **Prevenção de Fraude**: Detectar abusos, contas falsas
3. **Marketing**: Emails sobre novidades (apenas com opt-in explícito)
4. **Pesquisa**: Estudos de saúde populacional (dados anonimizados, opt-in)

### 3.3 O que NÃO Fazemos

- ❌ Vendemos seus dados pessoais
- ❌ Compartilhamos dados de saúde com anunciantes
- ❌ Usamos dados de ciclo para discriminação de preços
- ❌ Rastreamos localização precisa (apenas país via IP para LGPD/GDPR)
- ❌ Acessamos contatos, fotos, microfone, câmera sem necessidade

## 6. Retenção de Dados

| Categoria | Período | Critério |
|-----------|---------|----------|
| **Conta e Perfil** | Enquanto a conta existir + 30 dias após exclusão | Necessidade contratual |
| **Dados de Ciclo/Sintomas** | Enquanto a conta existir + 90 dias após exclusão | Histórico de saúde, LGPD Art. 16 |
| **Logs de Erro/Analytics** | 13 meses | Interesse legítimo, depuração |
| **Backups** | 30 dias (incremental), 90 dias (completo) | Recuperação de desastres |
| **Dados de Marketing** | Até revogação do consentimento | Consentimento |

**Direito ao Esquecimento**: Exclusão completa em até 30 dias após solicitação (LGPD Art. 18, GDPR Art. 17).

## 8. Segurança dos Dados

### 8.1 Medidas Técnicas
- **Criptografia em Trânsito**: TLS 1.3 para todas as comunicações
- **Criptografia em Repouso**: AES-256 para banco de dados local e backups
- **Chaves**: Android Keystore / iOS Secure Enclave para chaves locais
- **Certificate Pinning**: Prevenção de MITM em APIs críticas
- **Biometria**: Autenticação opcional para acesso ao app

### 8.2 Medidas Organizacionais
- **Princípio do Menor Privilégio**: Acesso apenas por necessidade
- **Treinamento**: Equipe treinada em LGPD/GDPR anualmente
- **Plano de Resposta a Incidentes**: Notificação em 72h (GDPR) / prazo razoável (LGPD)
- **Auditorias**: Revisão anual de segurança e privacidade

### 8.3 Armazenamento Local (Offline-First)
- Dados primários ficam no **dispositivo** (Realm Database)
- Sincronização opcional com nuvem (consentimento explícito)
- Você controla seus dados - eles são **seus**
