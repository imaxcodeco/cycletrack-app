Política de Privacidade - CycleTrack

Última atualização: 23 de novembro de 2026 · Versão 2.0

1. Introdução

Esta Política de Privacidade explica como o CycleTrack ("o app", "nós") coleta, usa e protege suas informações quando você usa o aplicativo de rastreamento de ciclo menstrual e saúde reprodutiva.

Estamos comprometidos com a conformidade com a LGPD (Lei nº 13.709/2018) e, na medida aplicável, com o GDPR (UE 2016/679).

2. Princípio central: seus dados ficam no seu aparelho

O CycleTrack foi desenhado para ser local-first: todos os dados de ciclo, sintomas, peso, temperatura, humor e conteúdo que você registra no app são armazenados apenas no armazenamento interno do seu aparelho (banco de dados local Realm). Esses dados não são enviados, sincronizados ou copiados para nenhum servidor nosso ou de terceiros.

Isso significa que:

  • Não temos acesso aos seus registros de ciclo, sintomas ou saúde.
  • Não compartilhamos esses dados com anunciantes, parceiros comerciais ou qualquer terceiro.
  • Se você desinstalar o app ou apagar os dados do aplicativo, essas informações são perdidas permanentemente (não há backup em nuvem).

3. Dados que coletamos

3.1 Dados de conta (Firebase Authentication)

Para usar o app, você cria uma conta com nome, e-mail e senha. Esses dados são processados pelo Firebase Authentication (serviço do Google) exclusivamente para permitir seu login e identificar sua sessão no aparelho. O Firebase Authentication não tem acesso aos seus dados de ciclo ou saúde — esses permanecem apenas no seu aparelho, conforme a Seção 2.

A senha é gerenciada diretamente pelo Firebase de forma criptografada; nós (desenvolvedores do app) nunca temos acesso a ela em texto puro.

3.2 Dados inseridos por você, armazenados localmente

Comprimento de ciclo, datas de menstruação, sintomas, peso, temperatura, humor, objetivo de uso, e dados de conteúdo salvo. Todos armazenados localmente, conforme a Seção 2.

3.3 O que o app NÃO coleta

  • Não usamos Google Analytics, Firebase Analytics ou qualquer SDK de analytics/telemetria de uso.
  • Não usamos SDKs de publicidade nem coletamos ID de publicidade.
  • Não acessamos localização, contatos, câmera, microfone ou fotos.
  • Não integramos com Health Connect, Google Fit ou Apple Health nesta versão.
  • Não processamos pagamentos nem temos recursos pagos nesta versão.

4. Compartilhamento de dados

Não vendemos nem compartilhamos seus dados pessoais com terceiros para fins de marketing ou publicidade. A única parte que processa dados (de conta, não de saúde) em nosso nome é:

ServiçoFinalidadeDados envolvidos
Firebase Authentication (Google)Login e gestão de sessãoNome, e-mail, senha (criptografada)

O recurso de "Modo Parceiro" do app simula localmente o compartilhamento com um parceiro, sem enviar dados para nenhum servidor — é uma funcionalidade apenas de demonstração nesta versão.

5. Retenção e exclusão de dados

  • Dados de ciclo e saúde: ficam no seu aparelho enquanto você usar o app; são apagados ao desinstalar o app ou limpar os dados do aplicativo nas configurações do Android.
  • Dados de conta (Firebase): mantidos enquanto sua conta existir.
  • Para solicitar a exclusão da sua conta e dos dados associados a ela no Firebase, envie um e-mail para o contato abaixo.

6. Seus direitos (LGPD)

Você pode solicitar, a qualquer momento, por e-mail:

  • Confirmação sobre quais dados de conta temos sobre você;
  • Exclusão da sua conta;
  • Esclarecimentos sobre esta política.

Como os dados de saúde ficam exclusivamente no seu aparelho, o acesso, a correção e a exclusão desses dados específicos são feitos diretamente por você, dentro do próprio app ou desinstalando-o.

7. Segurança

  • Comunicação com o Firebase Authentication usa conexão criptografada (HTTPS/TLS).
  • Dados locais ficam na área privada do aplicativo no Android, protegida pelo sistema operacional.

8. Crianças

O app não é direcionado a menores de 13 anos.

9. Alterações nesta política

Caso façamos mudanças materiais nesta política, atualizaremos a data no topo deste documento.
